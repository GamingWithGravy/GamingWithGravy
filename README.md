## OptiShade 1.0

[OptiShade](https://github.com/GamingWithGravy/OptiShade) is a per-game graphics and setup manager. Its Library scans games from supported storefronts and helps you install and manage OptiShade in compatible titles. A game appearing in the Library does not necessarily mean every OptiShade feature supports it; compatibility depends on the game, graphics API and installed components.

For **Microsoft Flight Simulator 2020 and 2024**, OptiShade brings together:

- NVIDIA and AMD image effects, presets and the Look Editor.
- Optional Neural Rendering and OptiMFG controls on supported NVIDIA RTX configurations.
- Glass Cockpit correction by IFreemz and optional AtmosphereMod support.
- In-game controls, per-game setup, updates, repair, restore and diagnostics.

OptiShade is free. Third-party components remain credited to their creators; see the [project credits](https://github.com/GamingWithGravy/OptiShade/blob/main/CREDITS.md).
